# Костер 3D — генератор моделей для 3D-печати

Веб-приложение для параметрической генерации круглых костеров (подставок под кружку)
под 3D-печать. Работает целиком в браузере, ничего не нужно ставить кроме Node для запуска.

**Онлайн-версия: https://3d.perseus.fyi/cup-holder-3d/**

## Возможности

1. **Размеры** — диаметр и толщина диска, фаска верхней кромки, гладкость.
2. **Логотип из SVG** — загрузка SVG, автоопределение заливаемых участков по цветам.
   Градиенты сводятся к одному цвету, а ползунок **«Объединять похожие цвета»** (порог
   ΔE) схлопывает близкие оттенки в один печатный цвет — со счётчиком «N оттенков → M
   цветов». Удобно для логотипов из трассировки/градиентов (десятки оттенков → 2–3 цвета).
   Положение: сдвиг, поворот, **«Центрировать»**, **«Макс. размер»**, тумблер
   **«Растянуть»** (без сохранения пропорций — заполнить грань целиком).
   Каждому участку можно назначить свой цвет печати. Три способа нанесения:
   - **Заподлицо (inlay)** — мультицветная вставка вровень с верхней гранью (идеально для MMU);
   - **Рельеф (emboss)** — выпуклый логотип над поверхностью;
   - **Гравировка (engrave)** — углубление одним цветом.
   Наложенные слои SVG компонуются корректно (верхний слой выигрывает — без z-fighting).
3. **Две надписи на нижней грани, напротив друг друга** (как на монете) — например,
   название по верхней дуге и год по нижней. Обе автоматически центрируются по дуге и
   читаются прямо при перевороте костера. Гравировка или рельеф, любой шрифт (.ttf/.otf).
4. **4 (2–8) глухих отверстия под ножки** — под мебельные демпферы. Регулируются
   диаметр, глубина, диаметр расстановки и угол.

## Экспорт

- **3MF (мультицвет)** — один объект, физически разбитый на части (3MF components):
  база + каждый цвет логотипа. Имена и экструдеры частей заданы для **OrcaSlicer/
  BambuStudio** (`Metadata/model_settings.config`) и для **PrusaSlicer**
  (`Metadata/Slic3r_PE_model.config`). Открывается как многосоставный объект;
  останется сопоставить экструдерам филаменты. Нужен профиль принтера с несколькими
  экструдерами/филаментами (MMU/AMS).
- **STL по цветам (zip)** — по одному STL на цвет + `colors.txt` с соответствием.
- **Один STL** — вся модель одной деталью.

Координаты в миллиметрах. Модель ориентирована для печати нижней гранью на стол
(логотип сверху печатается последним — удобно для смены цветов на верхних слоях).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Сборка статики: `npm run build` → `dist/` (можно открыть через `npm run preview`).

## Шрифты

В комплекте свободные шрифты PT Sans / PT Sans Narrow (ParaType, лицензия OFL, с
кириллицей) — в `public/fonts`, лицензия в `public/fonts/OFL.txt`. Любой свой шрифт
(.ttf/.otf) можно загрузить кнопкой «Загрузить шрифт» в секции надписи.

## Пример логотипа

`public/sample-logo.svg` — простой трёхцветный знак для проверки импорта.

## Подсказки по печати

- Для надписи снизу глубина гравировки 0.4–0.8 мм печатается чисто.
- Глубина отверстий под ножки должна быть меньше толщины (на дне остаётся стенка
  «толщина − глубина»); приложение предупреждает, если стенка получается тонкой.
- Если текст по дуге нужно пустить по верхней кромке — включите «буквы наружу».

## Технологии

TypeScript + Vite, рендер — three.js, булевы операции (CSG) — `manifold-3d` (WASM),
шрифты — `opentype.js`, разбор SVG — `SVGLoader` из three, ZIP/3MF — `fflate`.

## Тесты

`npm run smoke` — сборка геометрии во всех режимах + проверка экспортеров (без браузера).

## Структура

```
src/
  types.ts          модель параметров и дефолты
  manifold-setup.ts инициализация WASM
  modeling.ts       построение геометрии (база, фаска, ножки, логотип, текст)
  svg.ts            импорт SVG → цветные участки
  text.ts           шрифты и раскладка текста по дуге
  geom.ts           аппроксимация кривых, bbox
  viewer.ts         сцена three.js
  exporters.ts      3MF и STL
  ui.ts             панель управления
  main.ts           связывание всего
```
